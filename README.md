# LGU Document Flow

LGU DocTrack is a QR-based physical document custody system for local government offices. It now includes a React/TanStack frontend plus a Node.js Fastify API backed by Prisma and MySQL.

Core flows include login, role-scoped dashboards, document registration, QR routing slips, direct office-to-office receive/dispatch, wrong-office scan reporting, custody timelines, completion, filing, notifications, reports, analytics, and audit logs.

## Development

You need Node.js, npm, and MySQL.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
cp .env.example .env
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
npm run seed:test-reference
```

`seed:test-reference` loads eight active LGU routing templates and twelve common document types for manual testing. It is safe to rerun before documents are created; it refuses to replace the reference routes once test documents exist.

Run both services with the Windows network launcher:

```bat
run.bat
```

The launcher binds both services to all network interfaces and prints the current LAN URL. The frontend is served over HTTPS so phone camera access is available. From another device on the same Wi-Fi/LAN, open the printed network URL, for example `https://192.168.0.26:8081`. If Windows Firewall prompts for Node.js, allow private-network access.

The development certificate is generated by Vite and is not publicly trusted. On the phone, open the URL once, continue past the certificate warning, then reload the page. For a browser that refuses to continue, install a trusted LAN certificate or use a public HTTPS tunnel.

For API requests from other devices, set these values in `.env` to your computer's current LAN IP:

```env
FRONTEND_ORIGIN="https://localhost:8081,https://YOUR_LAN_IP:8081"
VITE_API_BASE_URL="https://YOUR_LAN_IP:8081/api"
```

The launcher fills these LAN values automatically. If you start the services manually, replace `YOUR_LAN_IP` with the computer's current IPv4 address.

Demo users from the seed data use password `demo1234`, including `admin@lgu.gov.ph`.

If Prisma reports `Environment variable not found: DATABASE_URL`, create `.env` first:

```bat
copy .env.example .env
```

Then edit `.env` so `DATABASE_URL` points to a real MySQL database and credentials on your machine.

## Progressive Web App

The production build is installable as a PWA from supported mobile and desktop browsers. It includes the LGU DocTrack app icon, standalone display metadata, and a service worker that caches the app shell and static assets for faster repeat access.

The system remains online-first: API requests and document custody actions are never cached or written offline. Serve the production build over HTTPS for installation and service-worker support; the service worker is registered only in production.
